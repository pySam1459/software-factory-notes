# Agent UI component images

Stills and marketing cards for agent frontend patterns. X posts were all amplify videos; frames below are API preview images. Full MP4 links are in [VIDEO-URLS.md](VIDEO-URLS.md). AffectUI live demos are JS-rendered React; static files here are the site's `/og/<slug>.jpg` cards (plus the category OG). Three component OGs were missing on the CDN (SPA HTML fallback only).

No image in this folder is over 2 MB; none needed compressing.
